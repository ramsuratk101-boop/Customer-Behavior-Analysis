# Customer Behavior Analysis and Repeat Purchase Prediction

## Overview

An end-to-end data analytics and machine learning project that analyses online retail transactions, segments customers using RFM analysis, and predicts customer repeat purchases within a 60-day period.

## Problem Statement

Understanding customer purchasing behaviour is essential for improving customer retention and business performance. This project uses historical retail transactions to identify valuable customer segments and predict future purchasing behaviour.

## Objectives

- Analyse customer purchasing patterns and sales trends.
- Segment customers using Recency, Frequency and Monetary (RFM) analysis.
- Identify high-value customer groups.
- Develop a machine learning model to predict repeat purchases within 60 days.
- Evaluate model performance using multiple validation techniques.

## Dataset

**Source:** UCI Machine Learning Repository – Online Retail Dataset

- Transaction data from December 2010 to December 2011.
- Includes invoice, product, quantity, price, customer and country information.

## Key Findings

- High-Value Active Customers contributed approximately 72.87% of recorded revenue.
- This segment represented approximately 30.24% of identified customers.
- The Logistic Regression model demonstrated useful repeat-purchase prediction performance.
